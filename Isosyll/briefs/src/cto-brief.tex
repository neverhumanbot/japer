\begin{minipage}[t]{0.486\textwidth}
  \vspace{0pt}
  \colheading{Per-Row Centred INT8 With Exact int32 Accumulation}
  {\fontsize{8.05}{10.0}\selectfont
  Weights are quantised offline per output channel ($s_w=\max|w|/127$). Activations are quantised per frame row around that row's own centre $c=\tfrac12(x_{\max}+x_{\min})$ with scale $s_a=(x_{\max}-x_{\min})/254$ and round-half-even, so one-sided post-SiLU activations use the full INT8 range. The output is recovered exactly as $y = s_a s_w\sum x_q w_q + c\,\bar w + b$, with $\bar w$ precomputed offline: centring costs one fused multiply-add per output.

  \vspace{2.5pt}
  Because $|x_q|,|w_q|\le127$, AVX2 pairwise products sum to at most $32{,}258<2^{15}$: the 16-bit step never saturates, and int32 accumulation equals the scalar reference bit for bit. Each row's scale depends only on that row, so a stream's tokens never depend on batch partners (verified for batch sizes 1--32).
  }
\end{minipage}\hfill
\begin{minipage}[t]{0.486\textwidth}
  \vspace{0pt}
  \colheading{Reproducible by Construction, Not by Tolerance}
  {\fontsize{8.05}{10.0}\selectfont
  \begin{itemize}[leftmargin=1.12em,itemsep=1.5pt,topsep=1pt]
    \item \textbf{Scalar reference:} forcing the portable scalar backend changes \ScalarDiffs{} of \ScalarUtts{} panel transcripts, so every SIMD kernel is checked against plain integer code.
    \item \textbf{Portable front end:} log-mel uses Cody--Waite reduction and polynomial $\sin$/$\cos$/$\log$ in unfused double arithmetic, so 1-ULP \texttt{libm} differences cannot flip quantisation ties.
    \item \textbf{Cross-ISA:} \CandIsaRuns{} witness decodes on Intel AVX2, AVX-512 VNNI and Apple M3 NEON reproduce the Zen~2 transcripts on all \ScalarUtts{} panel utterances; the v4.0.0 binary matches the signed reference decoders \ScalarUtts/\ScalarUtts{} on x86-64 and Apple silicon.
    \item \textbf{Weights:} safetensors, checked by SHA-256 at load.
  \end{itemize}
  }
\end{minipage}

  \briefsection{02}{Benchmark Method \& Paired Statistics}
  {\fontsize{7.85}{9.9}\selectfont
  \textbf{Single core, quiet host.} One process, one inference thread, pinned to one physical AMD Zen~2 core alone on its 4-core L3 complex; host timers and CI paused. Throughput is the median of three cold runs (audio-seconds per CPU-second), alongside peak RSS of the whole process tree.

  \vspace{2.5pt}
  \textbf{Paired, interleaved blocks.} Isosyll and Zipformer INT8 --- the strongest open streaming comparator near this cost and the teacher of our pseudo-labels --- ran in the same interleaved blocks on the same core. Speed, energy and memory ratios are medians of within-block ratios; WER differences use a paired speaker-cluster bootstrap.

  \vspace{2.5pt}
  \textbf{Selection honesty.} The 730-utterance panel overlaps the half of DEV used to pick settings, so we also report the unselected half (\CandCUtts{} utterances): live +LM trails Zipformer there by \textbf{\CandLiveLmCDelta\,pp} (bounds \CandLiveLmCLo{} to \CandLiveLmCHi). The model, v3.1.0 weights, missed its registered accuracy gates and was released by owner decision.
